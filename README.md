## 📖 About

This repository contains exercises and small programs written in **C**, developed during my studies in **Systems Analysis and Development (ADS)**. The goal here is to build a solid foundation in programming logic, algorithms, and problem-solving — skills I'm also applying toward building tech solutions for the legal field (LegalTech).

Each exercise is solved with clean, well-indented code and comments explaining the logic used, whenever necessary.

## 🗂️ Structure

```
c-programming-exercises/
├── 01-consumo-agua/
│   └── consumo_agua.c
├── 02-.../
│   └── ...
└── README.md
```

Each folder holds one exercise, named after its topic, with the `.c` source file and any supporting notes.

## ▶️ How to Compile and Run

Using GCC:

```bash
gcc nome_do_arquivo.c -o nome_do_programa
./nome_do_programa
```

- Basic input/output (`scanf` / `printf`)

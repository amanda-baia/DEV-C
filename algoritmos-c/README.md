# Algoritmos em C

Exercícios da disciplina **Algoritmos e Pensamento Computacional**, do curso de Análise e Desenvolvimento de Sistemas da UNIPÊ (Profa. Joanacelle Caldas).

Este repositório registra minha evolução na linguagem C, do primeiro `printf` aos algoritmos mais completos.

## Estrutura

| Pasta | Assunto | Aulas |
|---|---|---|
| [`01-entrada-e-saida`](01-entrada-e-saida) | Variáveis, tipos, `printf`, `scanf` e operadores | 2 e 3 |
| [`02-condicionais`](02-condicionais) | `if`, `else`, `else if` e `switch` | 4 |
| [`03-lacos`](03-lacos) | `for`, `while` e `do-while` | 5 |
| [`listas-professora`](listas-professora) | Listas de exercícios oficiais da disciplina | — |

## Exercícios

### 01 · Entrada e saída
| Arquivo | O que faz |
|---|---|
| `idade_daqui_5_anos.c` | Mostra a idade daqui a 5 anos |
| `dobro_triplo.c` | Calcula o dobro e o triplo de um número |
| `idade_em_dias.c` | Converte a idade de anos para dias |
| `gorjeta_total.c` | Calcula o total da conta com 10% de gorjeta |
| `media_3notas.c` | Calcula a média de três notas |
| `celsius_fahrenheit.c` | Converte Celsius para Fahrenheit |

### 02 · Condicionais
| Arquivo | O que faz |
|---|---|
| `situacao_aluno.c` | Média de duas notas e situação: aprovada, recuperação ou reprovada |
| `maioridade.c` | Informa se a pessoa é maior ou menor de idade |

## Como compilar e executar

Com o GCC instalado, dentro da pasta do exercício:

```bash
gcc nome_do_arquivo.c -o programa
./programa
```

No Windows (PowerShell), rode com `.\programa.exe`.
